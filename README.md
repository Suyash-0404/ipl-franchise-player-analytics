# IPL Franchise & Player Analytics

## Overview

An IPL analytics project designed to evaluate player,
team and venue performance and derive franchise-oriented insights.

## Objectives

- Evaluate player performance
- Compare team performance
- Analyze batting and bowling trends
- Analyze venue-level performance
- Compare player performance with auction value
- Identify potential high-performing talent

## Tools

- MySQL
- Excel
- Databricks
- SQL
- Data Cleaning
- Dashboarding

## Key Analysis

- Player performance
- Team performance
- Venue trends
- Player comparisons
- Auction-oriented analysis
- KPI analysis

## Key Insights

1. SRH's auction strategy delivers 132 ROI while KKR's ₹64 Cr overspend yields just 19 ROI, exposing massive franchise inefficiency.

2. Uncapped players like Kartik Tyagi, Anshul Kamboj offer 3x better value than marquee signings, suggesting franchises should prioritize undervalued talent over star power.

3. RCB's 78.57% win rate with moderate spending proves strategic player selection beats heavy starpower investment, while MI's ₹2.2 Cr minimal spend shows critical under-investment risks.

## Business / Franchise Relevance

The analysis can support franchise decision-making by helping
compare player performance, team requirements and potential
player value.
